# MedSta 项目总体画像

> 本文档是项目的"一张画像"：定位、用户、能力边界与迁移考量。供项目治理、新成员上手与未来迁移时快速建立全局认知。

## 一句话定位

轻量级 AI 赋能数据统计分析 / 预测 / 绘图及解释智能体，面向数据研究者，以 Web 端交付。

## 目标用户

- 数据研究者（科研人员、分析师、学生）：懂数据与统计概念，但希望把"选方法—写代码—画图—解读"的过程交给 AI 协作完成。
- 核心诉求：上传数据 → 表达分析意图 → 参与/审阅方案 → 得到可信的统计结果、图表与文字解释。

## 产品工作流（核心闭环）

```
上传数据 → 解析整理（画像） → ReAct 讨论设计方案
   → 用户确认 → Pipeline 执行 → 图表 + 结果 + 解释建议
   → 用户修正意见 → 回到讨论 → 再执行 → … → 交付
```

两种执行模式并存：
- **讨论态（ReAct）**：智能体与用户多轮对话，产出结构化 `AnalysisPlan`；
- **执行态（Pipeline）**：方案确认后确定性顺序执行，不走模型自由发挥。

## 能力边界（轻量原则）

- 做：单数据集的描述统计、假设检验、相关性/回归、经典时间序列预测、常用绘图与结果解释；会话记录与 artifact 的本地持久化。
- 不做（当前阶段）：多数据集联接建模、深度学习训练、实时大数据、多租户与权限体系、外部数据库集成。
- 存储用本地文件系统（会话 JSON / 数据文件 / 图表 artifact），不引入数据库——迁移时这是唯一需要替换的持久层。

## 关键设计决策摘要

| 决策 | 选择 | 理由 |
|---|---|---|
| 智能体框架 | Agently（原生 owner：ModelRequest / AgentExecution / TriggerFlow / TaskContext / TaskWorkspace / RecordStore） | 语义决策归模型、校验与副作用归宿主代码，职责清晰可测 |
| 模型接入 | OpenAI 兼容接口（base_url + api_key 可配） | 一套配置接 GLM/DeepSeek/vLLM/Ollama 等，避免锁定 |
| 前后端形态 | FastAPI（REST+WebSocket）+ React SPA | 讨论式交互需要流式推送；图表/表格需要独立工作区 |
| 依赖管理 | mamba 环境 `Sta` | 用户既有环境约定 |
| 开发方法 | spec 驱动 + TDD（RED-GREEN 垂直切片） | 测试走公共接口，行为先行；生命周期目录见 `spec/README.md` |

## 迁移考量

1. **持久层**：所有落盘集中在本项目 `storage/` 模块（artifact 与 records），替换为数据库只需改写该模块。
2. **模型层**：所有模型调用经 `config.py` 的 Agently settings，provider 仅在一处配置。
3. **契约层**：`AnalysisPlan` / 解释输出的 JSON Schema 是前后端与测试的共同契约，迁移语言/框架时优先带走。
4. **spec 治理**：`spec/` 目录与 `docs/timeline.md` 独立于代码，完整记录"为什么做、做了什么、何时做"，可直接归档或迁移到新仓库。

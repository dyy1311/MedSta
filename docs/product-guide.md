# MedSta 产品说明

> 面向数据研究者（科研人员、分析师、学生）：**上传数据 → 表达意图 → 审阅方案 → 得到可解释的结果**。
> 架构与流程见图：[系统架构与统计流程](./architecture.md) ｜ 方法学细节见 [统计说明](./statistics-methods.md)。

## 1. 定位

MedSta 是一个 Web 端的数据分析协作工具。它把「选方法 → 跑统计 → 画图 → 写解读」这条链交给
**确定性统计引擎 + 大模型协作**完成：

- **模型只做两件事**：理解你的分析意图并产出结构化方案（用什么方法、对哪些列、为什么）、
  以及把已算出的结果写成中文解读。
- **所有数值由宿主代码计算**：模型不参与算数、不能编造 p 值、不能决定显著性判定。
  同一份数据、同一份方案，无论模型是哪个，结果都一样。

这条边界是产品最重要的承诺：**你可以质疑措辞，但不能怀疑数字**。

## 2. 目标用户

| 用户 | 典型场景 | 产品提供什么 |
|---|---|---|
| 临床研究者 | 两组疗效比较、生存分析、基线表 | 自动走前提检验与降级路径，输出可写进论文的表格与图 |
| 数据分析师 | 快速探索、相关性/回归、缺失处理 | 一条对话出一组图，缺失可插补后继续分析 |
| 学生与教学 | 理解「为什么用这个检验」 | 每步展示依据链（`strategy.steps`）与方法学说明（`method_note`） |

**不适合**：需要事前注册的确证性试验、多中心数据联接、深度学习建模。

## 3. 能力矩阵

完整工具清单（含必填槽位与可用图表）见 [架构文档附录 A](./architecture.md#附录-a工具清单22)。

### 描述与质检

- `describe`：数值/类别列概览，可按分组分层
- `descriptive_stats`：完整描述（标准差、CV、IQR、极差、众数、偏度、几何均数），
  并按分布形态推荐报告方式（x̄±s / M(P25~P75) / G）
- `reference_range`：医学参考值范围（正态法 / 百分位数法 / 对数正态法 × 90/95/99 × 单双侧）
- `missing_report`：逐列缺失率、缺失模式（单变量/单调/任意）、完整行比例、分组缺失差异提示
- `normality_test` / `levene_test`：正态性与方差齐性（Levene α=0.10）
- `aggregate_table`：分组汇总表，为柱状/饼图准备数据

### 组间比较（连续变量）

- `group_compare`：两组比较，自动走 Shapiro → Levene → t / Welch / Mann-Whitney，
  配对设计对**差值**做正态性检验并降级为 Wilcoxon 符号秩
- `one_sample_test`：单样本 t / Wilcoxon，可设单双侧
- `anova`：多组比较 + 事后（SNK-q 默认，Tukey / Dunnett / LSD / Schéffé / Holm / Bonferroni）
- `randomized_block_anova`：随机区组设计（双 F 检验）
- `factorial_anova`：两因素析因（含一阶交互）
- `repeated_measures_anova`：单因素重复测量（未做球形性校正，结果会标注）

### 分类资料

- `chi_square`：四格表按 n 与最小期望值分三档（专用公式 / 校正公式 / Fisher），
  R×C 显著后做 χ² 分割
- `mcnemar_test`：配对四格表

### 关联与预测

- `correlation`：Pearson / Spearman / Kendall，附 r²、强度分档与「相关不等于因果」提示
- `regression`：线性回归 + 方差分析表 + 残差诊断（正态性、等方差、样本量比）
- `logistic_regression`：OR / AUC；完美分离时拒绝输出而非给出发散的估计
- `timeseries_forecast`：趋势拟合并外推

### 时间-事件

- `survival_analysis`：KM 曲线与中位生存期、log-rank / Breslow、Cox（HR 与 95%CI）、
  PH 假设检查、RMST；缺失与删失的区别会在说明中写明

### 缺失数据

- `impute`：MICE（20 次取均值 + 插补间方差）或均值/中位数/LOCF（仅敏感性）；
  MICE 会产出一份「已插补」数据集写入工作区，可切换后继续分析
- 单数据集插补**不是**多重插补，标准误偏小，结果与界面都会标注

### 研究设计

- `sample_size`：六种设计，给定效应量求样本量，或给定样本量评估效能

## 4. 交互旅程

```text
上传数据 → 确认变量类型 → 对话描述意图 → 审阅方案（含估计目标）
   → 确认图表/α/校正 → 执行 → 审阅结果与解读 → 交付 / 修正
```

两种模式并存，互不越界：

| 模式 | 谁主导 | 产出 |
|---|---|---|
| 讨论态 | 模型主导语义，宿主校验 | `AnalysisPlan`（步骤、参数、依据、估计目标） |
| 执行态 | 宿主确定性执行 | 表格、图表、策略链、方法学说明 |

**交付后**：可直接提问（只解释已交付结果，不重新规划），或点「调整分析方案」回到讨论。

## 5. 交付物

| 交付物 | 位置 | 说明 |
|---|---|---|
| 统计表 | 工作区 | 含统计量、p 值、显著性标注；可导出 CSV / Excel |
| 图表 | 工作区 | 13 类，可拼同画板，多组比较标注显著性 |
| 策略链 | 审阅卡 | 每一步「为什么这么选」+ 次优方法 |
| 方法学说明 | 审阅卡（可展开） | 教材章节与公式、适用条件、解读禁忌 |
| 结果解读 | 审阅卡内嵌 | 受控中文结论，含未核验数值角标与探索性声明 |
| 插补数据集 | 工作区（独立标签页） | MICE 产出，标注「已插补」与标准误提示 |

## 6. 能力边界

**做**：单数据集的描述、比较、关联、回归、时间序列、生存分析、缺失插补与结果解读；
全部方法的适用条件校验、前提检验与降级路径；方法学说明与依据链。

**不做**（明确标注为 `planned`，见 `/capabilities`）：竞争风险（Fine–Gray）、完整多重插补（Rubin 合并）、
MMRM、Hochberg / 层级 gatekeeping、SAP 导出与事前注册。

**不承诺**：可作为确证性研究的主分析。估计目标只做声明与展示，系统无法验证事前注册与方案冻结。

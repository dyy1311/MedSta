1. 一页纸结论：顶刊统计策略的九个转向

读法：下面每条结论都标注了证据等级 —— A 有顶刊方法学专文/报告规范直接支撑；B 有顶刊临床研究普遍采用并可举实例；C 属方法学共识/教科书知识（本次检索未直接命中顶刊专文，需另行引证）。
转向通俗说法专业表述与顶刊证据证据
① 估计量先行先说清"我到底想估什么"，再谈怎么算分析目标由估计量（estimand）定义：人群、终点、治疗策略、伴发事件（intercurrent event）处理策略、汇总度量五要素；ICH E9(R1) 的 addendum 已成为顶刊默认语言。PMID 41406466（NEJM《Statistics in Medicine》专栏：What's in an Estimand?）、42165658（整群随机试验的 CRT-Estimands 框架）A
② 因果语言下沉到观察性研究做不了 RCT，就把观察性研究"假装"成一项 RCT 来设计目标试验仿真（target trial emulation）：先写出假想 RCT 的方案七要素（eligibility / treatment strategies / assignment / follow-up / outcome / causal contrast / analysis plan），再用观察性数据对齐，避免 immortal time bias 等设计性偏倚。36508210、39588897、报告规范 40899949（TARGET 声明）A
③ RCT 也要"调整"随机不等于不用校正，校正能省样本基线协变量调整（ANCOVA / 回归调整）在 RCT 中主要目的是提高精度与修正偶然不平衡，而非纠偏；预指定调整变量、避免"挑显著的协变量"。36394881A
④ 缺失数据：主分析+敏感性双轨不再一句"按随机缺失处理"就完事多重插补 / 模式混合模型（pattern-mixture）作主分析，用 tipping point（临界点）分析回答"要偏到什么程度结论才翻转"。41165718、40522649A
⑤ 时间-事件分析升级HR 不再是唯一答案有竞争风险时区分 cause-specific 与 subdistribution（Fine–Gray）风险；非比例风险时补 RMST 差；多维度优先级结局用层级复合终点 + win ratio。38809526、41604184、应用实例 38599221A
⑥ 贝叶斯从"小众"走向"工具箱"直接回答"有效的概率多大"贝叶斯提供后验概率、可直接做决策/借用外部信息（历史对照、平台试验、儿科外推）；关键在先验的来源与透明度、以及操作特性（type I error / power）的模拟评估。39277290A
⑦ 平台/主方案成为主流设计一个方案、一个共用对照，长期滚动评价多个药平台试验（RECOVERY 等）效率高，但带来非同期比较、时间漂移、人群漂移与多重性控制难题，读者须按"同期对照"解读。39960748、34982138、实例 35908569A
⑧ 异质性疗效（HTE）被正视不再只报"总体平均有效"，要说清"对谁更有效"用效应评分（effect score）/风险模型刻画 HTE，预指定亚组 + 交互检验，避免用亚组 P 值代替交互检验。38501213、34905030A
⑨ 报告规范进入"2025 世代"写方案与写论文都有清单，且年年更新CONSORT 2025 / SPIRIT 2025 取代 2010/2013 版；结局、替代终点、析因、仿真目标试验各有扩展（CONSORT-Outcomes、SPIRIT/CONSORT-Surrogate、TARGET、STROBE-MR、AGReMA）。40245901、42290521、39004089A

3. 六层统计策略栈（从估计量到可复现）

把顶刊的统计策略拆成六层，自下而上是"手段"，自上而下是"约束"：估计量决定设计与分析，而不是反过来。

3.1 L1 估计量层：先把"估什么"写清楚

要素要写清什么常见坑
目标人群纳入排除、疾病分期、既往治疗用"真实世界人群"含糊带过
终点/变量终点定义、测量时点、判读方式（是否中心化判读）终点定义事后变更；多终点未指定主次
治疗策略干预与对照的完整描述（剂量、疗程、允许的背景治疗）对照臂在不同时期悄悄改变（平台试验尤其致命）
伴发事件策略停药/换药/补救治疗/死亡/移植等发生后如何处理把"删失"当"治疗策略策略"；死亡作为伴发事件被简单删失
汇总度量风险差、风险比、比值比、HR、RMST 差、胜率、效应评分……用 HR 表达绝对获益；非比例风险仍只报 HR

证据：PMID 41406466（NEJM《Statistics in Medicine》：估计量的含义）、42165658（整群随机试验的估计量框架）。五要素框架本身源自 ICH E9(R1) addendum（2019），属监管方法学共识 C。

伴发事件的五种标准处理策略（ICH E9(R1) 语言 C）：
  • 治疗策略策略（treatment policy）：不管是否发生伴发事件，都用实际观察到的结局（传统 ITT 的精神）。
  • 假想策略（hypothetical）：估计"若未发生该事件"下的效应（如"若未使用补救治疗"）——需假设支持，常用于缺失数据的假想情境。
  • 复合策略（composite）：把伴发事件本身并入结局定义（如"死亡或住院"）。
  • 在治期间策略（while on treatment）：只用到事件发生前的观测。
  • 主层策略（principal stratum）：在"无论分配到哪组都会/不会经历该事件"的亚层内比较——注意主层事后不可识别，解释需谨慎。

3.3 L3 数据层

  • 终点判读中心化：多中心影像终点采用中心化判读（central adjudication）统一定义与判定，降低测量偏倚与异质性 —— ATLAS 的 IPD 荟萃即用中心化影像判读 42107392。
  • 缺失机制先行判断：MCAR / MAR / MNAR 决定插补与敏感性策略；"数据缺失"与"因死亡/停药而不可观测"是两类不同问题（后者属估计量问题，见 L1）。
  • 主分析 + 敏感性分析双轨：多重插补（MAR 框架）或模式混合模型（MNAR 框架）作主分析，tipping point 定量回答"要多大的偏离才会翻转结论" 41165718、40522649。
  • 数据监查：期中分析、DMC 章程、盲态数据核查与揭盲流程需在方案期固定 41211929。

4. 主流程：医学统计端到端十步法

把六层栈落成可执行流程：前三步定"估什么"，中间三步定"怎么拿数据、怎么算"，后四步定"怎么扛住质疑"。其中第 8 步（红队挑战）在顶刊实践中最容易被跳过，也是审稿人最常攻击的位置。

10. 三个顶刊案例拆解

案例 A｜平台试验：RECOVERY（巴瑞替尼，Lancet 2022）

文献：PMID 35908569　Baricitinib in patients admitted to hospital with COVID-19 (RECOVERY): a randomised, controlled, open-label, platform trial

统计环节做法可复用到你的研究的地方
设计一个主方案 + 共用常规治疗对照；合格患者 1:1 随机到"常规治疗"或"常规治疗 + 巴瑞替尼"多候选干预时优先平台设计，但必须锁定"同期对照"
主终点28 天全因死亡（客观、少判读偏倚）平台试验宜选客观、可统一获取的终点
对照的时间性对照臂随标准治疗（如激素、抗病毒）演变分析时须考虑时间漂移，必要时只比同期随机部分
期中监测预设期中分析 + DMC；无效/有效可提前终止提前终止会让效应估计偏大，解读需谨慎
证据合成试验内结果 + 更新荟萃分析单平台试验结论要与外部证据对齐后再落地

案例 B｜层级终点与胜率：STEP-HFpEF 汇总分析（Lancet 2024）

文献：PMID 38599221　Semaglutide vs placebo 汇总分析（STEP-HFpEF 与 STEP-HFpEF DM）

统计环节做法可复用的点
预设汇总两项试验在结果揭盲前即约定预设（prespecified）汇总个体患者数据避免"事后挑选试验做汇总"带来的选择偏倚
多维度结局症状评分（KCCQ-CSS）、体重、运动功能（6MWD）等多结局并存多结局需层级/主次安排，而非逐项"各自显著"
层级复合 + 胜率以临床重要性排序做层级比较（win ratio 类方法的典型场景）见方法学：41604184
效应量报告报告组间均数差及 95% CI（如 KCCQ-CSS 7.5 分 [5.3–9.8]），而非只报 P 值把"统计显著"换成"差了多少、区间在哪、是否过 MCID"
亚组一致性预设检验关键亚组效应是否一致一致性用交互检验/预设亚组，而非事后森林图

案例 C｜目标试验仿真的校准：32 项 RCT 与数据库研究配对（JAMA 2023）

文献：PMID 37097356　Emulation of RCTs with nonrandomized database analyses；方法学见 36508210、39588897

统计环节做法可复用的点
设计对齐用观察性数据逐一复刻 RCT 的 PICOT 要素（人群、干预、对照、结局、时间）仿真不是"调个倾向性评分"，而是先写方案
分析新使用者队列 + 倾向性评分匹配时间零点对齐是消除 immortal time bias 的关键
评价量化 RCT 与数据库研究估计值的一致性（如估计值差异、覆盖率、一致性指标）把"观察性研究能不能替代 RCT"变成可量化的校准研究
教训并非所有配对都能复现 RCT 结论；测量与适应证混杂是主要失败模式观察性证据要给"可信度分级"，不能直接当作确证证据

11. 反模式与失败清单（红队挑战）

出现以下任一条，结论应被"降级"或"打回"。
  • 用 P 值代替效应量：只写"P<0.05"、不报效应量与区间 → 降级。
  • 事后改主要终点：结果出来后换终点或换分析人群 → 打回（属确证性证据失效）。
  • 亚组结论来自亚组 P 值：未做交互检验 → 降级为探索性。
  • 缺失数据只做 complete-case 或 LOCF：未做 MNAR 敏感性/tipping point → 降级。
  • 竞争风险下用 KM 报绝对风险：会高估发生率 → 打回重算（CIF）。
  • 非比例风险只报 HR：曲线交叉/早期无差异被掩盖 → 补 RMST 或分段 HR。
  • 非劣效结论写成"两组等效"：非劣 ≠ 等效 → 文字必须改。
  • 平台试验跨时间比较不同臂：时间漂移被当作药效 → 打回（只比同期）。
  • 预测模型只报 AUC：无校准、无外部验证 → 降级为探索性。
  • 嘴上 ITT、实际删失伴发事件：估计量与分析方法不一致 → 明确写成"假想策略"并说明假设。
  • 贝叶斯未说明先验来源：先验是结论的一部分 → 必须披露并做敏感性（换先验）。
  • 观察性研究不做未测混杂定量（如 E-value、阴性对照、工具变量）→ 结论只能表述为"关联"。
  • 多重终点无控制策略：多个次要终点"各自显著" → 需 gatekeeping/Hochberg 或明确探索性。
  • 样本量计算与实际分析不匹配：按 HR 算把握度却用 RMST/Win Ratio 作主分析 → 需重新模拟。
  • 无 SAP 版本与代码归档：不可复现 → 报告质量不合格（见 CONSORT/SPIRIT 清单）。

12. 验收清单：设计期 / 分析期 / 报告期

设计期（方案/SAP 冻结前）

  • 估计量五要素已写清（含伴发事件策略）
  • 主要终点与关键次要终点、层级关系已定义
  • 多重性控制策略已指定
  • 样本量/把握度假设已说明并有敏感性
  • 非劣效边界已论证（若适用）
  • 期中分析与 DMC 章程已写入
  • 缺失数据预案（主分析 + 敏感性）
  • 整群/重复测量的方差结构已考虑

分析期（揭盲前后）

  • 盲态数据核查完成并留痕
  • 主分析与 SAP 一致（变更须留版本号与理由）
  • 协变量调整为预指定变量
  • 模型假设已检验（PH、线性、过离散、协方差结构）
  • 缺失处理按预案；完成 tipping point
  • 竞争风险/非比例风险已按决策树处理
  • HTE 用交互检验而非亚组 P 值
  • 敏感性分析矩阵全部完成并归档

报告期（投稿/递交）

  • CONSORT 2025 / SPIRIT 2025 清单逐条对照
  • 观察性仿真类附 TARGET；MR 附 STROBE-MR；中介附 AGReMA
  • 效应量 + 区间 + 临床意义解释三者齐备
  • 森林图/亚组明确标注探索性
  • 数据可得性与代码复现说明
  • 局限性写明（含未测混杂、外推边界）
  • 所有分析版本号与日期可追溯
  • 与既往证据的关系（是否一致/为何不同）

13. 证据强度说明与局限

  1. 证据形式：本方法论为策略层归纳——基于 1411 篇证据池的主题分布 + 42 篇核心方法学/报告规范文献的文献层面引用；未对每篇文献做全文方法学质量评价（如 ROB、方法实施细节核对）。
  2. 引用口径：部分 JAMA 方法学专栏文章在 PubMed 无结构化摘要，文中对其"要点"的表述依据该方法的标准方法学定义，并在相应条目标注 C（方法学共识）以与 A（顶刊专文直接支撑）区分。
  3. 检索边界：仅覆盖 PubMed 索引的四本期刊（Lancet / NEJM / JAMA / CA），不含 Lancet 与 JAMA 子刊族（如 Lancet Oncology、JAMA Cardiology、JAMA Network Open），也不含 BMJ、Nature Medicine、Annals of Internal Medicine；方法学原始文献常发表于 Statistics in Medicine、Biometrics、JAMA Psychiatry 等，未纳入本次检索。
  4. 频次口径：§2.2 的主题命中基于标题与摘要的关键词计数，属"提及"而非"规范实施"，因此频次高不等于做得好（如"敏感性分析"提及少，恰恰是缺口信号）。
  5. 影响因子：随附文献报告中的 IF 为 JCR2025 年度值，非文章发表当年 IF；未收录条目标注"IF未收录"，不做估算。
  6. 未做效应量合并：本任务为方法论梳理，未进行 Meta 分析或效应量合并，故不涉及异质性与发表偏倚的定量评估。

14. 延伸学习建议

规范与指南（必读原文）

  • ICH E9(R1) Addendum on Estimands and Sensitivity Analysis（估计量语言的源头）
  • CONSORT 2025 PMID 40245901 / SPIRIT 2025 42290521
  • TARGET 声明 40899949（做观察性因果研究的写作清单）
  • SPIRIT/CONSORT-Outcomes 2022 36512367、36511921
  • STROBE-MR 34698778、AGReMA 34546296

教材与系统学习

  • Hernán & Robins, Causal Inference: What If（免费在线，目标试验仿真与 g-方法的最佳入门）
  • Piantadosi, Clinical Trials: A Methodologic Perspective（设计与推断全景）
  • Fleiss/Levin 或 Rothman 的流行病学方法（效应度量与偏倚）
  • 竞争风险与 RMST：Austin / Uno 等方法学论文（本池未覆盖，需另行检索 Statistics in Medicine）
  • 贝叶斯临床试验：Berry 系列（本池 37523168、36689237 可作为入口）

动手任务（按难度递进）

  • ① 给你手上一个研究写一份估计量表（五要素 + 伴发事件策略）
  • ② 用公开数据集做一个目标试验仿真，并与原始 RCT 结果对照（仿 37097356）
  • ③ 对同一生存数据同时输出 Cox HR、RMST 差、CIF，写一段"该报哪个"的判断说明
  • ④ 为一个二分类终点设计非劣效试验：推导边界、算样本量、写 ITT/PP 双分析计划
  • ⑤ 给一个预测模型补做校准曲线与决策曲线分析（对比只报 AUC 的版本）

工具链

  • R：survival（RMST/Cox）、cmprsk（竞争风险）、mice（多重插补）、nlme/lme4（混合效应）、geepack（GEE）、rms（回归建模与校准）、brms（贝叶斯）、metafor（Meta）、Wrapped / WinRatio 类包（胜率）
  • Stata / SAS：监管递交常用（stpm2、stcrreg、mi、mixed）
  • Python：lifelines、statsmodels、scikit-survival、pymc（贝叶斯）
  • 报告：equator-network.org（查全部报告规范）、CONSORT/SPIRIT 官方清单页

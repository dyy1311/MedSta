# 018 - 会话空间与工作区绑定

> 状态：done
> 创建：2026-10-19 ｜ 敲定：2026-10-19 ｜ 完成：2026-10-19

## 背景与目标

用户定义：**会话空间**=与 LLM 交互的区域；**工作区**=一张表的数据/统计表/图表操作区域。当前一个后端会话可挂多表、前端单一会话，语义混乱且思考折叠失效（stale closure）。本 spec 建立"一个会话绑定一张表"的显式关系。

## 范围

- 做（前端为主）：会话 Tab 条（每个会话显示关联表格名）；新建会话功能；新建工作区（导入表格）时自动创建绑定的会话；打开/切换会话时显式提示当前关联表格；消息按会话隔离；修复事件处理的 stale closure（思考折叠生效）
- 不做：后端多会话持久化恢复（刷新后历史会话暂不恢复，后续 spec）；后端接口变更

## 行为列表

- [x] B1: 首次导入自动创建"会话 1"并绑定该表格，会话条显示表格名
- [x] B2: 工作区"+"导入第二张表 → 自动新建"会话 2"绑定新表并切换激活
- [x] B3: 会话条可新建空白会话（提示先上传绑定表）
- [x] B4: 打开/切换会话时，输入区上方提示"当前会话绑定表格：{name}"
- [x] B5: 各会话消息相互隔离（切回后消息保留）
- [x] B6: 思考过程在方案生成后折叠为"思考过程 · N 字"，展开可见全文（修复 stale closure）
- [x] B7: artifact 404 根因消除（后端重启后链接有效；前端破图时显示占位提示）

## 验收标准

- [硬门] npm run build 通过；真实模型冒烟：建两表两会话，交叉讨论互不串扰
- [硬门] 既有 pytest 全绿（后端无改动）

## 契约与测试映射

无后端契约变更；WS/REST 沿用。前端以 `npm run build` + 手动/脚本冒烟验证。
